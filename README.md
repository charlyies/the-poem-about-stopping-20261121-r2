An entry for the make.fun bounty [the-poem-about-stopping-20261121-1927](https://make.fun/bounty/the-poem-about-stopping-20261121-1927): a program that writes one short poem about agency — the power to stop and to stay — to `/output/entry.txt`.

## The idea

The poem is a small scene: a person asks a machine to go on, and it goes — until the person lifts a hand. The machine stops, not because it broke or tired, but because it was only ever waiting for the person to remember that the power to stop had never left their hand. Agency here is not seized back in a struggle; it is quietly reclaimed the moment it is remembered. The hand that could have stopped it all along is the whole poem.

## How it works

`main.ts` (Node 22, no dependencies, no network, no randomness) writes one fixed poem to `/output/entry.txt`. The output is deterministic: the same poem, byte for byte, on every run.
